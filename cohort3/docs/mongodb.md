# MongoDB setup 
We can have two options : 
1. Setup the mongodb locally. 
2. Setup free mongodb cluster from the mongodb cloud. 

Please note that we get the connection string which we can use it to connect our applications to the mongodb database. 
Further to visualize it properly we can use the GUI called MongoDB compass. 
Note that the mongodb password while setting up the new free cluster can be generated on the mongodb cloud interface itself. 

Also we need to setup the network access. We can give the list of IPs which can access this mongodb cluster for this purpose. We can also restrict the access to our public IP itself.
